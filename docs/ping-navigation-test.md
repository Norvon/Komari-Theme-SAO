# Ping 时间窗口测试版

测试包：`Komari-Theme-SAO-N-v1.1.7-test.2.zip`，包含上一测试版的加载改进，不新增图表依赖。

## 交互

- Ping 继续使用 uPlot，默认显示最近 24 小时；整体可选范围最多 90 天，受服务端保留时间限制。
- 主图左右拖动平移，滚轮围绕鼠标位置缩放；最短窗口 5 分钟，双击或点击“回到最近 1 天”重新对齐当前时间。
- 底部时间选择器拖动中间选区平移、拖动左右手柄调整时长。手柄支持左右方向键，Shift 加速到一天，Home/End 到边界。
- 保留全部历史快捷档位；自定义窗口不再错误高亮“最近某小时/某天”。
- 底部仅显示时间范围，不预先请求 90 天概览或原始数据。松开指针或停止滚轮 250ms 后按窗口请求；按住暂停不会提前查询，曲线与统计使用同一起止时间，旧请求可取消。
- 切换范围时保留同节点已加载曲线作为占位，并明确提示统计暂为上次结果；空窗口和请求失败时仍能操作选择器。
- 本次不修改负载交互、丢包含义和缺失样本的连线规则。服务端已聚合或未记录的短时断联，不能靠缩放还原。

## 接口边界

上游源码确认 `public:queryMetrics`、`public:getPingMetricStats` 和 `common:getRecords` 支持带时区的 `start`/`end`。核对版本：`e48aa1e76931132fb5dc93ce53763dd59df83d9f`，对应 [metric 接口](https://github.com/komari-monitor/komari/blob/e48aa1e76931132fb5dc93ce53763dd59df83d9f/web/rpc/jsonrpc/public.metric.go) 和 [records 接口](https://github.com/komari-monitor/komari/blob/e48aa1e76931132fb5dc93ce53763dd59df83d9f/web/rpc/jsonrpc/common.record.go)。实际部署版本仍需站点验证。

绝对窗口查询失败时可以回退到支持时间窗口的 RPC records；不会改用尚未确认支持绝对窗口的旧 HTTP 路径冒充选中的历史时间。前端核对回传的 start/end 或 from/to；服务端缺少相应方法或忽略窗口时会明确提示升级。统计范围不匹配时改由曲线样本计算。原有不传窗口的调用继续保留 HTTP 兼容路径。

## 站点验收

1. 登录并打开节点 Ping，确认默认最新一天，底部总范围不超过保留期和 90 天。
2. 拖到昨天凌晨/下午四点附近，缩小到一小时以内，核对坐标、提示框与 Network 的 start/end；断联是否有原始记录须另行确认。
3. 连续拖动、滚轮缩放、切换快捷档位，确认停止操作后才查询，不会由旧响应覆盖新窗口。
4. 点击最近一天和刷新，确认重新对齐当前时间；拖到最早和最新边界不能越界。
5. 测试空数据、超时、401/403、快速切换节点，以及手机横向拖动、纵向滚动和键盘手柄操作。

本地单测与模拟接口浏览器验证不等同于登录后的线上性能和历史数据准确性验证。回退可重新上传 `Komari-Theme-SAO-N-v1.1.7-test.1.zip`，不涉及数据迁移。
