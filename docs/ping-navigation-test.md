# Ping 时间窗口验证说明

发布包：`Komari-Theme-SAO-N-v1.1.7.zip`，功能与 `1.1.7-test.4` 一致，包含此前测试版的加载改进、时间窗口导航和手柄起止时间提示，修复关闭断点连线后仍跨过缺采样的问题，不新增图表依赖。

## 交互

- Ping 继续使用 uPlot，默认显示最近 24 小时；整体可选范围最多 90 天，受服务端保留时间限制。
- 主图左右拖动平移，滚轮围绕鼠标位置缩放；最短窗口 5 分钟，双击或点击“回到最近 1 天”重新对齐当前时间。
- 底部时间选择器拖动中间选区平移、拖动左右手柄调整时长。手柄支持左右方向键，Shift 加速到一天，Home/End 到边界。
- 悬停、键盘聚焦或调整时间窗口时，手柄旁显示开始和结束日期、时间，跟随当前选区实时更新，不等待接口返回；两端提示上下错开，并限制在时间条宽度内。
- 保留全部历史快捷档位；自定义窗口不再错误高亮“最近某小时/某天”。
- 底部仅显示时间范围，不预先请求 90 天概览或原始数据。松开指针或停止滚轮 250ms 后按窗口请求；按住暂停不会提前查询，曲线与统计使用同一起止时间，旧请求可取消。
- 切换范围时保留同节点已加载曲线作为占位，并明确提示统计暂为上次结果；空窗口和请求失败时仍能操作选择器。
- 关闭“断点连线”时，超过采样周期及时间容差的缺口保留断点，不再自动跨过 2～6 个周期的缺采样。后端聚合数据以返回的聚合间隔判断；正常相邻桶、多线路错相采样和容差内的时间抖动不会被误判为缺口。开启后仍可跨空缺连线。
- 多线路长缺口整段保留空白，包含其他线路的错相锚点和新增断点，不再只在前几个采样周期断开；没有其他锚点的缺口只补一个断点，避免按缺测时长扩张数组。
- 空白表示缺少采样或丢包，不代表已经确认服务器离线，也不把缺测补成 100% 丢包；统计仍按接口实际记录计算。部分丢包的聚合桶仍保留成功样本延迟，不伪造桶内的离线起止时间。可以缩小范围查询更细的数据，但服务端已聚合且无细粒度记录的中断无法还原。本次不修改负载交互。

## 接口边界

上游源码确认 `public:queryMetrics`、`public:getPingMetricStats` 和 `common:getRecords` 支持带时区的 `start`/`end`。核对版本：`e48aa1e76931132fb5dc93ce53763dd59df83d9f`，对应 [metric 接口](https://github.com/komari-monitor/komari/blob/e48aa1e76931132fb5dc93ce53763dd59df83d9f/web/rpc/jsonrpc/public.metric.go) 和 [records 接口](https://github.com/komari-monitor/komari/blob/e48aa1e76931132fb5dc93ce53763dd59df83d9f/web/rpc/jsonrpc/common.record.go)。实际部署版本仍需站点验证。

绝对窗口查询失败时可以回退到支持时间窗口的 RPC records；不会改用尚未确认支持绝对窗口的旧 HTTP 路径冒充选中的历史时间。前端核对回传的 start/end 或 from/to；服务端缺少相应方法或忽略窗口时会明确提示升级。统计范围不匹配时改由曲线样本计算。原有不传窗口的调用继续保留 HTTP 兼容路径。

## 站点验收

1. 登录并打开节点 Ping，确认默认最新一天，底部总范围不超过保留期和 90 天。
2. 拖到昨天凌晨/下午四点附近，缩小到一小时以内，核对坐标、提示框与 Network 的 start/end；断联是否有原始记录须另行确认。
3. 连续拖动、滚轮缩放、切换快捷档位，确认停止操作后才查询，不会由旧响应覆盖新窗口。
4. 点击最近一天和刷新，确认重新对齐当前时间；拖到最早和最新边界不能越界。
5. 测试空数据、超时、401/403、快速切换节点，以及手机横向拖动、纵向滚动和键盘手柄操作。
6. 拖动两端手柄或中间选区，确认起止时间立即更新；在最短窗口、最早/最新边界和手机窄屏下，提示不重叠、不超出时间条，原有手柄仍可操作。
7. 保持“断点连线”关闭，定位已知缺测时段：按 5 分钟聚合返回的数据缺少 20～30 分钟时，曲线应留白；单个缺失桶也应断开，其他连续线路不应被切断。开启后可连线，再关闭应恢复留白。缩小到该时段，核对实际响应的时间、聚合间隔及丢包记录，不将缺测视为已确认离线。

本地单测与模拟接口浏览器验证不等同于登录后的线上性能和历史数据准确性验证。回退可重新上传 `Komari-Theme-SAO-N-v1.1.7-test.3.zip`，不涉及数据迁移。

## 本地验证记录

已使用生产构建、独立临时 Chrome 配置和本地模拟 RPC，验证默认一天/上限 90 天、主图平移、滚轮缩放、底部选区和手柄、键盘最早边界、按住停顿不查询、窗口与统计参数一致、旧请求取消、最近一天复位、空数据和 401 后仍可导航、390px 移动布局与模拟触摸横向拖动/纵向滚动，以及 12 小时保留期下的初始范围裁剪。浏览器未出现未捕获异常。

未连接真实站点，未验证 Safari、真机触摸、多线路大数据量或生产查询耗时。

起止时间提示已通过本地 Chrome 模拟接口验证：主图拖动、底部选区和手柄拖动时实时更新；390px 触摸拖动及键盘最短 5 分钟窗口下，提示上下错开且不越过时间条边界。该验证不替代 Safari 或真机测试。

缺口修复已通过回归单测及生产构建的本地 Chrome 模拟 RPC 验证：5 分钟聚合数据中的 20、30、105 分钟缺口、单个缺失桶和显式丢包均整段留白；另一条持续采样的错相线路不断开。读取实际 uPlot 裁剪区间核对缺口覆盖，开启/关闭断点连线及开启削峰平滑后结果符合预期。部分丢包的聚合桶保留成功样本延迟，不据此伪造离线区间。尚未核对真实站点昨天的历史响应。
